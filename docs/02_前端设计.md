## 四、Tooltip 系统

**规则：所有可交互图标按钮必须有 Tooltip。**

```tsx
// Tooltip 结构
<Tooltip>
  <TooltipTrigger asChild>
    <button>...</button>
  </TooltipTrigger>
  <TooltipContent side="bottom">
    <div className="font-semibold">固定到今日</div>
    <div className="text-muted text-xs">将任务添加到今日计划</div>
    <kbd className="kbd">⌘T</kbd>  {/* 有快捷键时显示 */}
  </TooltipContent>
</Tooltip>

// 触发延迟：300ms
// 危险操作额外显示警告：
<TooltipContent>
  <div className="font-semibold text-red-500">删除任务</div>
  <div className="text-xs">⚠ 此操作不可撤销</div>
  <kbd>Del</kbd>
</TooltipContent>
```

**所有需要 Tooltip 的位置清单：**
- 侧边栏所有图标（折叠状态时）
- 看板列操作按钮（筛选/排序/添加）
- 任务卡片操作（优先级/截止日/完成/删除/编辑）
- 甘特图工具栏（缩放/今日/导出）
- 顶部导航图标（通知/搜索/头像）
- 详情面板所有图标
- 论文 Hub 操作按钮

## 六、动效规范

```tsx
// 页面视图切换
<motion.div
  initial={{ opacity: 0, y: 8 }}
  animate={{ opacity: 1, y: 0 }}
  transition={{ duration: 0.15 }}
/>

// 右侧详情面板滑入
<motion.div
  initial={{ x: '100%' }}
  animate={{ x: 0 }}
  exit={{ x: '100%' }}
  transition={{ type: 'spring', damping: 30, stiffness: 300 }}
/>

// 任务卡片拖拽
拖起：scale(1.02) + shadow-lg，旋转 1deg
放下：spring 弹回
落点列：背景色高亮 + 虚线边框

// 任务完成
打勾：绿色缩放动画（0 → 1，100ms）
标题：划线从左到右（200ms）
卡片：淡出（opacity 0, 300ms）

// 番茄钟结束
页面边缘：绿色光晕脉冲（3次）
+ 系统通知

// Deadline 临近（≤3天）
日期标签：红色 + 轻微脉冲动画
卡片左侧：红色竖条

// Modal/弹窗
进入：opacity 0→1 + scale 0.97→1（150ms）
退出：opacity 1→0 + scale 1→0.97（100ms）
背景遮罩：blur 渐入
```

### 8.2 每个视图的 ⓘ 使用说明

各视图右上角固定 ⓘ 图标，点击显示该视图专属说明：

- **看板**："拖拽卡片到不同列更改状态 / 点击列顶部 + 新建任务"
- **甘特**："拖拽任务条调整日期 / 拉伸左右边缘调整时长 / 点击打开详情"

- **专注模式**："选择任务后点击开始 / 番茄钟结束自动记录工时"

### 8.3 空状态（Empty State）

每个空列表都有：插画 + 说明文案 + 行动按钮

## 十二、各视图详细交互

### 看板（Kanban）

```
列：待办 | 进行中 | 完成
列顶部：任务数量 + 排序 + 筛选
卡片内容：标题 + 优先级色条 + 截止日 + 子任务进度 + 协作者 Avatar
卡片操作（hover 显示）：完成✓ / 编辑✎ / 删除🗑 / 更多⋯
拖拽：列间拖拽改状态，列内拖拽排序
快速新建：点击列底部 [+ 添加任务]，直接输入标题回车
```

### 甘特（Gantt）

```
纵轴：Project 分组
横轴：日期（可缩放：天/周/月）
任务条颜色：按 Space 主色
交互：
  拖拽整条：移动时间段
  拖拽左边缘：调整开始日期
  拖拽右边缘：调整截止日期

  依赖连线：箭头显示前置关系
工具栏：今日 | 本周 | 本月 | 缩放 | 导出PNG
```
