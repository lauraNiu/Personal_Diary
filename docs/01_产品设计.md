# Personal Life OS — 产品设计书

> 版本：v1.0 | 日期：2026-05-15

---

## 一、产品定位

一个面向个人的全生命周期任务管理系统，覆盖学术科研、职场工作、个人生活三大领域，以 AI Agent 为核心驱动力，实现"输入一句话，AI 帮你管好一切"。

---

## 二、核心数据结构

```
Space（空间，可自定义，不限数量）
  └── Area（子分类）
        └── Project（项目）
              └── Task（任务）
                    └── Subtask（子任务）

横跨所有 Space 共用：
  Collaborator（协作者）
  Tag（自定义标签）
  Meeting（会议）

学术专属：
  Paper（论文）
    └── PaperSnapshot（版本快照）
  Journal（期刊库）
```

## 三、三大空间详细设计

### 🎓 学术空间

| 模块 | 内容 |
|------|------|
| 论文管理 | 绑定 Overleaf 项目、每日自动拉取快照、字数增长曲线、版本对比 |
| 投稿追踪 | 目标期刊（含影响因子/截稿日）、投稿状态流转 |
| 合作者管理 | 和谁合作、和谁对齐、最近同步时间、相关任务列表 |
| 会议管理 | 时间/参会人/Agenda/会后 Action Item |
| 截稿 Deadline | 会议截稿、期刊截稿、独立 deadline 总览视图 |
| 科研任务 | 可挂接论文/合作者/研究方向多个维度 |

**投稿状态流转：**
```
准备中 → 已投稿 → 在审 → 小修 / 大修 → 接受 / 拒稿
```

### 💼 工作空间

| 模块 | 内容 |
|------|------|
| 项目 & 需求 | 项目进度、需求拆解、排期管理 |
| 会议 & 汇报 | 周会/月会/汇报，AI 生成 Agenda |
| Code Review | 关联代码任务，记录 review 状态 |
| OKR / 目标 | 季度目标 → 关键结果 → 任务分解 |
| 文档 & 笔记 | 关联任务的备注文档 |

### 🌱 生活空间

| 子分类 | 内容 |
|--------|------|
| 社交 & 约会 | 约会计划、朋友聚餐、社交事项 |
| 阅读计划 | 书单、读书进度、读书笔记 |
| 技能学习 | 英语打卡、音乐练习、其他技能 |
| 健身运动 | 运动计划、打卡记录 |
| 日常事务 | 购物、家务、行政事项 |
| 财务记录 | 账单提醒、支出记录 |

## 四、任务完整属性

```yaml
Task:
  基础信息:
    - 标题（必填）
    - 描述（Markdown 支持）
    - 原始输入文本（AI 解析来源，可溯源）

  分类维度:
    - 所属 Space
    - 所属 Area（可选）
    - 所属 Project（可选）
    - 关联 Collaborator（可多个）
    - 关联 Paper（学术任务，可选）
    - 标签（自定义颜色，可多个）

  时间维度:
    - 开始日期
    - 截止日期
    - 预估工时（小时）
    - 实际工时（时间追踪）
    - 重复规则（每天/每周X/每月X/自定义）

  状态维度:
    - 优先级：🔴 紧急 / 🟠 高 / 🟡 中 / 🟢 低
    - 状态：Inbox → 待办 → 进行中 → 完成 → 取消

  关系维度:
    - 前置任务（依赖，A 完成后 B 解锁）
    - 子任务 checklist（可嵌套）

  提醒配置:
    - 提前 N 天邮件提醒
    - 站内通知开关
```

## 五、Collaborator（协作者）设计

```yaml
Collaborator:
  - 姓名
  - 邮箱（可选，用于会议邀请）
  - 角色：导师 / 学生 / 同事 / 合作者 / 其他
  - 所属机构
  - 头像色（随机分配，用于 Avatar）
  - 关联任务列表
  - 最近同步时间（AI 自动追踪）
  - 备注
```

协作者视图可按人过滤所有任务、会议、论文。

## 六、Paper（论文）设计

```yaml
Paper:
  - 标题
  - 关联 Project
  - Overleaf 项目 URL
  - 目标期刊列表（可多个，排序表示优先级）
  - 投稿状态（准备中/已投/在审/修改/接受/拒稿）
  - 截稿日期
  - 合作者列表
  - 当前版本字数
  - 版本快照列表:
      - 快照时间
      - 版本标签（v1.0/v1.3/...）
      - 字数
      - AI Diff 摘要（本次改了什么）
      - 文件本地路径
  - 字数增长曲线数据
```

## 七、Meeting（会议）设计

```yaml
Meeting:
  - 标题
  - 时间 + 时长

  - Action Item 列表（可转化为任务）
```

## 八、Journal（期刊库）设计

```yaml
Journal:
  - 名称（全称 + 缩写）
```

## 九、AI Agent 全部能力

### 被动触发（用户输入时）

| 能力 | 输入 | 输出 |
|------|------|------|
| 语义建任务 | 任意自然语言 | 结构化任务（所有字段自动填充）|
| 任务拆解 | 一个大目标 | 带时间节点的子任务清单 |
| 会议 Agenda | 会议目的 + 参会人 | 议程 + 预填 Action Item |
| 期刊推荐 | 论文摘要 / 关键词 | 最匹配期刊列表（含截稿日）|
| 工作量估算 | 任务描述 | 预估完成时间（基于历史数据）|

### 主动触发（后台持续运行）

| 能力 | 触发条件 | 建议示例 |
|------|---------|---------|
| 今日计划 | 每天 07:50 / 用户输入可用时间 | 按优先级+类别分配时间块 |
| 截稿进度预警 | 论文 N 天未更新 + 距截稿 < 21 天 | "EMNLP 还剩 18 天，论文已 7 天未更新" |
| 协作者同步提醒 | 与某人超过 14 天未同步 | "建议本周约张老师同步一次" |
| 连续拖延感知 | 某任务连续 3 天标为"待办"未动 | "这个任务已拖延 3 天，是否需要拆解？" |
| 时间冲突检测 | 同日多个高优任务 | "周五有 3 个 deadline，建议提前重排" |
| 效率洞察 | 每周分析历史数据 | "你每周三完成率最高，建议深度工作放周三" |
| Overleaf Diff | 每次同步后 | "本次新增实验章节约 800 字，方法章节有修改" |
| 月度复盘 | 每月 1 日 | 自动生成上月个人成长报告 |
| 情绪感知 | 连续拖延同类任务 | "你已连续 5 天未完成学习类任务，是否需要调整计划？" |

### 邮件通知系统（Gmail SMTP）

| 邮件类型 | 发送时间 | 内容 |
|---------|---------|------|
| 每日摘要 | 每天 08:00 | 今日任务清单 + AI 建议 + 紧急预警 |
| 截稿预警 | 提前 14/7/3/1 天 | 论文/任务详情 + 当前完成进度 |
| 周回顾 | 周日 20:00 | 完成/拖延/时间分布 + 下周重点建议 |
| 紧急播报 | 实时 | 任务距截止 < 24h |
| 月度复盘 | 每月 1 日 09:00 | AI 生成完整个人月报 |

## 十、Overleaf 集成流程

```
每日定时任务（02:00 AM）：
  1. 用 Cookie 请求 Overleaf API
  2. 下载项目最新版本（ZIP）
  3. 解压 → 统计 .tex 文件总字数
  4. 与上次版本对比字数变化
  5. 调用 GLM-4 生成 Diff 摘要
  6. 保存快照（本地文件 + SQLite 元数据）
  7. 更新字数增长曲线数据

用户手动触发：
  - 任意时间点击"立即同步"按钮
  - 同步完成后前端实时刷新
```
